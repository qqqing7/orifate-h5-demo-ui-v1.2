v1.2 前端测试

六个独立版本，首页设计各不相同，但交互与功能已统一到 V2 标准：色彩分析单一路径（拍照 → 直接看结果 / 补答六题）、体型只走手工尺寸、我的页为「我的穿搭方案 / 穿搭日历 / 色彩分析 / 体型分析」、衣橱导入只留拍照与相册、分析完成后首页入口自动收起。

测试建议：用 Chrome / Edge 打开；每个版本独立存储，切换版本不会互相影响。想做色彩分析：首页入口 → 开始拍照分析 → 上传一张正面照 → 选「直接看初步结果」或「补答六题」。

V2 接了 Dify：色彩分析 / 穿搭推荐 / 衣橱识别需要本地 Node 后端（server/），静态托管下只用于预览界面与其余流程；V1、V3、V4、V8、iPhone16 为纯前端规则，全部可离线使用。
